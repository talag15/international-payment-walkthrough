The API calls, in order

          

            
#CallWhat it does

            
              
1POST /product-applicationsOne-time application for international payments. Nium verifies the business, and Unit opens a USD wallet for it.

              
2POST /counterpartiesSaves Union's bank details (SWIFT code and IBAN) once.

              
3POST /quotesLocks a rate for £1,000 and returns the dollar total.

              
4POST /paymentsUses the quote to debit $1,366.35 and start delivery.

              
5AutomaticUnit and Nium fund, convert and pay out. The app is notified by webhook.

The price is locked, briefly
A quote holds the rate for a set time, from 5 minutes to 24 hours depending on the provider. If it expires, the app requests a new one.

      
No double payments
Each request carries an idempotency key, and a quote can be used only once. A retry or double-click never pays Union twice.

      
Exceptions are handled by people today
If money comes back after the debit (a return, or a failed conversion or funding), Unit's operations team resolves it.
